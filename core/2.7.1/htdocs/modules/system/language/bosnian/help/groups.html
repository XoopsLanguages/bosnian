Pomoć: Grupe

Opis

XOOPS uključuje sistem registracije članova - opciono možete zahtijevati od ljudi da se prijave na vašu stranicu kako bi imali pristup određenim područjima ili funkcijama. Na primjer, većina web lokacija zahtijeva da se ljudi pridruže prije nego im se dozvoli da doprinose vijestima ili postavljaju poruke na forumima.
Prava pristupa i administracije XOOPS web stranice se postavljaju putem fleksibilnog sistema dozvola zasnovanog na 'korisničkim grupama'. Zadane grupe uključuju anonimne korisnike, registrirane članove i webmastere, ali naravno možete definirati onoliko grupa koliko vam je potrebno za upravljanje vašom web lokacijom. Svaka grupa može dobiti jedinstven skup prava pristupa koja regulišu:

- Koji blokovi se mogu vidjeti
- Kojim modulima se može pristupiti
- Koji moduli se mogu administrirati
- Koji aspekti sistemske administracije se mogu mijenjati

Možete promijeniti nazive ovih zadanih grupa, ali ih ne možete izbrisati. Ostale korisničke grupe se također mogu postaviti i definirati kao što će biti razmotreno kasnije.

Prilagođene grupe se također mogu kreirati preko stranice administracije grupa.
