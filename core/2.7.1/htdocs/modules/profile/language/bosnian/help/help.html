OPIS

Modul Profil je za upravljanje prilagođenim poljima korisničkog profila.

INSTALIRAJ/DEINSTALIRAJ

Nisu potrebne posebne mjere, slijedite standardni proces instalacije – raspakirajte /profile folder u direktorij ../modules. Instalirajte modul preko Admin -> System Module -> Modules.

Detaljna uputstva o instalaciji modula dostupna su u XOOPS Operativni priručnik

UPUTSTVO ZA RAD

Za postavljanje ovog modula potrebno je:

  • Konfigurirajte svoje postavke za modul (pogledajte 'Preference') i opciono blok Profile ako ga namjeravate koristiti (pogledajte 'Blokovi').
  • Uredite postojeće kategorije ili dodajte nove.
  • Uredite postojeća polja ili dodajte nova. Ovdje možete odrediti koja polja će biti vidljiva u kojoj kategoriji i da li će biti vidljiva prilikom registracije korisnika.
  • Definišite redosled koraka registracije.
  • I konačno, možete podesiti dozvole za pojedinačna polja - koja se mogu uređivati, koja pretraživati.

Mere protiv neželjene pošte

Da biste smanjili registraciju neželjene pošte, uradite sljedeće:

  • idite na modul Protector u Admin, idite na Preferences, a zatim na dnu, na ovu opciju: "Stop Forum Spam" Provjerava POST podatke u odnosu na spamere registrovane u bazi podataka www.stopforumspam.com.
    Postavite na "Ban IP (bez ograničenja)"

  • u /class/captcha/config.php, uvjerite se da je mod postavljen kao "tekst":

    return $config = array(
    'disabled' => false, // Onemogući CAPTCHA
    'mode' => 'tekst', // zadani način rada, možete odabrati 'text', 'image', 'recaptcha' (zahtijeva api ključ)
    'name' => 'xoopscaptcha', // captcha ime
    'skipmember' => istina, // Preskoči CAPTCHA provjeru za članove
    'maxattempts' => 10, // Maksimalan broj pokušaja za svaku sesiju
    );

  • U modulu Profil idite na Admin i u Osnovnom koraku koji se nalazi na:
    /modules/profile/admin/step.php?id=1
    postavite "Sačuvaj nakon zaustavljanja" na "Ne"


  • U Postavkama profila, postavite opciju "Koristi Captcha nakon drugog koraka registracije" na "Da" (to je zadano)
