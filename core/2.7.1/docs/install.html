Instaliranje XOOPS-a

Prva instalacija

Predgovor:

XOOPS je open-source Objektno orijentisani sistem za veb objavljivanje napisan u PHP-u. Idealan je alat za razvoj malih do velikih web stranica dinamične zajednice, portala unutar kompanije, korporativnih portala, weblogova i još mnogo toga.

XOOPS se izdaje pod uslovima GNU Opća javna licenca (GPL) verzija 2 ili novija i besplatna je za korištenje i modificiranje. Slobodna je za redistribuciju sve dok se pridržavate uslova distribucije GPL-a.

Zahtjevi

  • WWW server (Apache, NGINX, IIS, itd.)
  • PHP 8.2 ili više, preporučuje se 8.4+
  • MySQL 5.7 .8 ili noviji, preporučuje se MySQL 8.4.5+

Prije instalacije

  1. Ispravno podesite WWW server, PHP i server baze podataka.
  2. Pripremite bazu podataka za svoju XOOPS lokaciju.
  3. Pripremiti korisnički nalog i odobriti korisniku pristup bazi podataka.
  4. Učinite direktorije i datoteke upisivim: %s
  5. Iz sigurnosnih razloga, preporučujemo vam da premestite dva direktorija ispod korijen dokumenta i promijenite nazive foldera: %s
  6. Kreiraj (ako već nije prisutan) i upiši u direktorije: %s
  7. Uključite kolačiće i JavaScript u vašem pretraživaču.

Instaliranje lokalno

Ako koristite lokalno okruženje za razvoj ili testiranje, uvjerite se da imate prethodno ispunjeni zahtjevi. Kada to učinite, kopirajte sadržaj htdocs direktorij (iz XOOPS distribucijsku datoteku) na stazu korijenskog dokumenta vašeg web okruženja. Kada se fajlovi tamo kopiraju, možete započeti instalaciju usmjeravanjem vašeg pretraživača na "http://yoursite.com". Ovo će pokrenuti proces instalacije.

Instaliranje na hostovanoj platformi

Ako radite u hostiranom okruženju, raspakujte XOOPS datoteke lokalno ili na serveru ako imate pristup ljusci (tj. SSH). Kada završite, obavezno premjestite ili kopirajte sve XOOPS datoteke iz htdocs direktorij do vašeg korijenskog web direktorija (vaš provajder obično daje ovu lokaciju s uputama). Nakon što se datoteke tamo kopiraju, možete započeti instalaciju tako što ćete usmjeriti na pretraživač "http://yoursite.com". Ovo će pokrenuti proces instalacije.

Nastavak instalacije

Samo pratite uputstva korak po korak u instalateru.
